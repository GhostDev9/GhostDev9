# GhostDev9

**Building and researching Dazroki — a private, local-first autonomous software engineering system.**

My approach to engineering comes from twenty years of military service involving surface sonar systems. That background reinforced habits that remain central to my technical work: understanding sensor behavior, isolating faults, checking assumptions against observations, documenting complex systems, and treating uncertain results as a reason to investigate rather than guess.

Today I am applying those habits to software architecture, AI-assisted development, local inference, security testing, workflow automation, and systems integration. Dazroki is the primary research project bringing these interests together.

## The Dazroki research project

I am developing Dazroki as a locally operated AI orchestration engine intended to take a substantial project through planning, bounded execution, verification, recovery, and delivery. The long-term goal is not a chatbot that writes a single script; it is a controlled system that can complete a defined engineering project with evidence explaining what happened and what remains uncertain.

My work examines:

- How to keep authorization separate from AI-generated plans and retrieved content.
- How to isolate execution and protect private workspaces on a local Linux host.
- How to recover from interrupted operations without repeating unknown side effects.
- How to connect source revisions, testing and observed results to release decisions.
- How to make long-context local inference practical without misleading performance claims.
- How to develop specialized, real-world project workflows beyond common assistant demonstrations.

## How I work

I set the requirements, research system behavior, make architecture and risk decisions, and review results. I use ChatGPT for design analysis and independent assessment, Gemini as a coding assistant, and Visual Studio Code for local editing and review. Tests and release evidence are intended to be generated on my own machine. AI output is an input to engineering judgment, not proof of correctness or permission to deploy.

Dazroki is **private and under active development**. Security and recovery testing has identified unresolved release blockers. I do not represent the system as production-ready, independently certified, or capable of unattended operation until those conditions are actually verified.

This GitHub profile is a public record of the research direction and engineering lessons. The private Dazroki source, system configurations, operational logs and security evidence are not published here.
